# Pro 组长业务模块与依赖

实施已完成并随 PR #2 合入 main 的 1b89ce8。本页是当前模块索引；逐文件预估与实施前方案见[历史方案](../archive/2026-10-19-组长业务模块方案.md)，不再要求重新规划或重新实现已交付模块。

| 层 | 模块 | 职责 |
|---|---|---|
| Gateway | security、filter | 可信头、JWT role、internal 和 exchange 治理 |
| 目录 | capability_client、capability_config | 新鲜快照、显式 internal/market、失败关闭 |
| 输入 | schemas、input_validation | 有界输入与内联 JSON Schema |
| 执行 | capability_adapters、model_client | 聊天/摘要和模型/Mock/降级 |
| 编排 | chat_service、conversation_store、execution_billing、completion_result | 会话、预检、结算收据和追踪 |
| Web | features/chat、ChatPage | 选择能力、Schema 输入、结果与调用核验 |
| 验收 | leader_e2e、chat-browser、CI | 独立资源真实链与桌面/手机验收 |

依赖单向，不跨库，不根据目录 service/path 执行任意地址。单价来自目录，降级 cost=0。当前限制和证据见[完成记录](../组长业务完成记录-2026-10-19.md)，接口见[Pro 契约](../api-contract/ai-chat-service.md)及[共享约定](../api-contract/pro-shared.md)。

内部目录服务端、实时管理员和 Key 兑换待成员交接；市场兼容模式不替代严格内部验收。
