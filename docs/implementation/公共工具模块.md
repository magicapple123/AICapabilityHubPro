# Pro 公共工具模块说明

公共工具已随 PR #1 合入 main；本页说明当前边界。原始规划见[历史方案](../archive/2026-10-18-公共工具模块方案.md)，不作为重新实施任务。

| 入口 | 职责 |
|---|---|
| scripts/init_dev.py | 首次配置/独立依赖；保留已有 .env |
| scripts/start_pro_local.py | 推荐 Pro 并行端口和共享密钥连接 |
| scripts/start_leader_dev.py | 组长组件的显式目录模式 |
| scripts/start_dev.py | 默认端口组件入口，不能混用配置 |
| scripts/smoke_check.py | 只读经网关检查，不扣分 |
| scripts/Invoke-QualityGate.ps1 | 离线聚合检查与唯一报告目录 |
| scripts/check_test_report.py | 严格核验 JUnit；拒绝 DB 跳过 |
| scripts/contract_lint.py | 统一契约、边界、可提交凭据候选检查 |
| scripts/run_leader_e2e.py | 独立资源、真实服务/浏览器，模型端替身 |

基线说明见[公共基础完成记录](../公共基础完成记录.md)。当前启动/验证命令以[开发指南](../../AICapabilityHubPro-开发指南.md)为准；工具不授予删除配置、停止未知进程或取消 Review 的权限。
