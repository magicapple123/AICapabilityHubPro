### 黄禹菲：user、billing与Settings

- 注册默认user，防止注册/资料自助指定admin；角色模型、登录信息及保留旧账号的增量迁移。
- GET /internal/user/authorization，核对调用身份与当前数据库状态/role。
- POST /api/user/apikeys/exchange：摘要/所有者/账号/Key禁用和过期、短JWT与TTL硬上限，不泄露凭证。
- billing保留已有capability_id/points/requestId/状态/耗时，兼容扩展unit_price存储/查询/幂等；不伪造历史未知价格。
- 全局统计实时admin保护；个人积分/明细隔离。补齐user check目标ID比较和扣分重放字段冲突负例。
- Settings拆分资料、角色、Key生命周期和积分组件，secret不写持久化存储。
- 覆盖撤权/禁用、授权故障、Key状态/TTL、余额不足、重复/冲突记账、旧库迁移和真实UI。

### 夏思凯：capability与市场/运营

- GET /internal/capability/{id}返回匹配ID/code/真实status/内联param_schema/整数price_per_call。
- 分类/能力写、上下架及运营列表实时调用user authorization；撤权、禁用和依赖异常均拒绝。
- chat-completions/long-summary输入、状态、示例单价与已实现adapter一致；视觉等没有执行器不可体验。
- 市场按钮传/chat?capability_id=<id>；真实价格/Schema/可用性展示，Console错误态明确。
- 市场不泄露service/path/secret或草稿/下架存在性；覆盖内部详情、软删除、价格/Schema边界、重复编码、权限/浏览器入口。
- 内部详情交接后与组长验收strict internal，不能用market兼容结果代替。
