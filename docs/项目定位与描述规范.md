**一句话简介**

面向开发者的 AI 能力执行与计量平台，以能力目录驱动聊天与文本摘要，提供 Schema 输入校验、按能力计费和 requestId 全链路追踪。

**GitHub About**

**英文简介**

AICapabilityHub Pro is a developer platform for capability-driven AI execution, schema-aware inputs, per-capability billing, and request tracing. It combines Spring Cloud Gateway, FastAPI services, and a React workspace, with controlled chat and text-summary executors and isolated integration tests.

## 新旧版本的叙述顺序

对外介绍先说明 Pro 的用户价值，再说明实现和边界：选择能力 → Schema 对应输入 → 状态与余额预检 → 受控聊天/摘要执行 → 目录价计量 → 费用与 requestId 核验。

旧版本重点是网关、用户、目录、计费、聊天等服务的基础搭建。Pro 的差异是能力 ID、Schema、价格、执行器和结果追踪形成同一条业务链，而不是只给旧仓库加一个后缀。

技术栈用于解释这条链路如何运行，不替代产品介绍。不使用“企业级全能力平台”“已支持任意模型插件”“生产可用”等未经实现和验收支持的描述。角色与Key兑换可按已验证范围介绍，但不等于部署、供应商验收或完整生产安全保证。
