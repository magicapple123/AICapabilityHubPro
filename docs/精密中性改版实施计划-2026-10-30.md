# AICapabilityHub Pro —「精密中性」界面改版实施计划

> 版本：2026-10-30 · 适用于 `D:/AICapabilityHubPro/web`
> 设计基准：`artifacts/ui-redesign-proposal-20261030/index-v2.html`（可交互预览，含 5 个页面与折叠态）
> 本文档可直接交给新对话执行，无需回看历史讨论。

---

## 0. 一句话目标

在**不改业务逻辑、不改路由、不改接口**的前提下，把现有前端从"米白 + 淡墨绿 + 小字号"的旧视觉，整体切换为"冷灰底 + 近黑字 + 单一靛蓝强调"的精密中性视觉，并补上可折叠侧栏与重排后的登录页。

---

## 1. 背景与已确认决策

| 项 | 决策 |
|---|---|
| 视觉方向 | 精密中性（Precision），参考 Linear / Stripe 的"单强调色 + 细线分层 + 收束字阶" |
| 强调色 | 靛蓝 `#3a34a8`，**每屏只允许 1 个实心主操作** |
| 品牌标记 | 01 叠片（三层错位圆角方块），24 网格单色矢量 |
| 侧栏 | 可自由展开 / 收起，宽度 236px ↔ 76px，240ms 过渡 |
| 登录页 | 居中卡片内左右分栏（左品牌 / 右表单），去掉全屏硬分割线 |
| 深色模式 | 本期不做，但 token 需可逆（颜色全部走变量） |
| 聊天页 | **保留现有"历史 + 主区"两栏结构**，不引入预览稿里的右侧参数栏（现有 SchemaForm 在底部，交互不能改） |

---

## 2. 硬约束（违反会导致回归，务必遵守）

1. **不新增后端不存在的功能**：不加"记住此设备""忘记密码""API Key 登录""单点登录"。预览稿里的这些元素只是版式占位，落地时删除。
2. **不删除已有功能**：登录页必须保留账号/密码、注册模式（昵称字段）、CapsLock 提示、错误提示、loading 锁定、注册/登录切换、DEV 演示账号填入、`env.useMockLogin` 提示。
3. **保留现有类名与组件边界**：优先改 CSS 与 token，TSX 只做必要的结构调整。禁止为了套样式重写页面逻辑。
4. **不引入新依赖**：不装 Tailwind 插件、不装 UI 库、不装字体包。字体沿用系统栈。
5. **不动 antd 的功能性配置**：只改 `ConfigProvider` 的 `token`，不改 `locale`、不改组件行为。
6. **不使用 `!important` 堆叠**：antd 覆盖优先通过 `ConfigProvider` token + 提高选择器特异性。
7. **中文断行**：正文容器加 `text-wrap: pretty`；标题、描述避免行末只剩 1–2 个字。

## 3. 设计基线

### 3.1 颜色令牌

| 用途 | 值 | 说明 |
|---|---|---|
| 页面底色 | `#f5f6f9` | 冷灰，替代旧 `#f8f8f6` |
| 卡片面 | `#ffffff` | |
| 次级面 | `#fafbfd` / `#f1f3f8` / `#e8ecf3` | surface-2/3/4 |
| 描边 | `#e5e9f1` | 常规 |
| 强描边 | `#d3d9e5` | 输入框、分割 |
| 细线 | `#edf0f6` | 表格行、卡内分隔 |
| 主文字 | `#0e1626` | 近黑，不用 `#000` |
| 次文字 | `#46536a` | |
| 辅助文字 | `#6f7b8f` | 最小 11px 时使用 |
| 弱文字 | `#98a2b3` | 仅用于装饰/占位/表头 |
| 强调 | `#3a34a8` / hover `#2b2685` / 淡底 `#eeeffb` / 淡边 `#dcdcf4` | |

| 警告 | `#8a6420` on `#fbf2e2` | |
| 失败 | `#a33a30` on `#fbebe8` | |

### 3.2 字阶（全站只允许这几个尺寸）

| 角色 | 字号 / 行高 / 字重 |
|---|---|
| 微标签（全大写、表头） | 9–9.5px / 1.5 / 600 + `letter-spacing:.09em` |
| 辅助信息 | 10.5–11px / 1.6 / 400 |
| 正文 | 12–13px / 1.7 / 400 |
| 卡片标题 | 13.5–14px / 1.5 / 600 |
| 页面标题 | 26px / 1.2 / 600 / `letter-spacing:-.035em` |
| 指标数字 | 26–28px / 1.2 / 600 / tabular-nums |
| 登录页主标题 | 34px / 1.34 / 600 / `-.045em` |

所有数字（金额、积分、耗时、ID）加 `font-variant-numeric: tabular-nums`；ID 与代码用等宽栈 `"SF Mono","JetBrains Mono",Consolas,monospace`。

### 3.3 几何

- 圆角只有三种：卡片 `12px`、按钮/小控件 `7px`、输入框 `8px`、胶囊 `999px`。
- 间距刻度：`4 / 6 / 8 / 10 / 12 / 14 / 18 / 24 / 32`，不出现 13、17、23 这类奇数。
- 内容宽度：`.page` `max-width:1240px`，左右 padding 30px。
- 卡片阴影只用两档：
  - 常态 `0 1px 2px rgba(16,24,40,.04)`
  - 悬浮 `0 1px 2px rgba(16,24,40,.04), 0 10px 24px -18px rgba(16,24,40,.35)`

### 3.4 层级规则

- 卡片靠 **1px 描边 + 极淡阴影** 分层，不靠重阴影。
- 悬停只允许：描边变深 / 上移 1–2px / 阴影加深，三者最多同时两项。
- 按钮按重要性分三级：**实心（每屏 1 个）/ 描边（默认）/ 纯文字（辅助）**。

## 4. 品牌标记：01 叠片

24×24 网格，单色，`currentColor`，最小 16px 可用。

```svg

```

用法：
- 侧栏 15–16px，白色 on 深色方块（`#0e1626` 底，28px，圆角 7px）。
- 登录页 15px，同样处理。
- 深色底上用 `opacity` 会产生灰阶，**不要**改成三种不同色值。

## 8. 已知风险与规避

| 风险 | 规避 |
|---|---|
| 旧 CSS 大量硬编码色值，只改 token 会出现"新旧混杂" | 批次 3/4 必须把对应文件里的 hex 全部换成变量，用 `grep -n "#[0-9a-f]\{6\}" src/styles` 自查，只允许 tokens.css 内出现 hex |

| 登录页重排后丢失注册模式 | 按 5.9 的清单逐条核对；注册字段与校验逻辑原样保留 |
| 加动画导致低端机掉帧 | 只用 `transform` / `opacity`；`prefers-reduced-motion` 下禁用 |
| 市场卡片在列表视图被新样式撑破 | `.market-list` 的 grid 列宽同步调整，375px 下走单列 |
