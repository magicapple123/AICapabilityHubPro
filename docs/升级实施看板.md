## 4. 新功能验收对照

| 新功能 | 相对旧版的差异 | 验收方式 | 主要负责人 |
|---|---|---|---|
| 市场一键体验 | 由浏览目录改为选择目录项并进入真实调用流程 | 点击能力后检查 capability ID、表单/Schema 和调用结果 | 夏思凯 + 黄岑果 |
| Schema 驱动输入 | 按能力显示合适参数，不把不相容能力伪装成同一个聊天接口 | 错误输入返回校验错误，模型客户端调用数为 0 | 黄岑果 + 夏思凯 |
| 按能力计价 | 从固定 POINTS_COST/能力 ID 为 0 改为目录单价贯穿链路 | 对账价格、账单 cost 和扣分流水 | 三人联调 |
| API Key 兑换短期 JWT | 从 Key 管理扩展到实际调用凭证使用 | 验证有效/错误/过期/禁用凭证及 TTL 上限 | 黄禹菲 + 黄岑果 |
| 服务端角色授权 | 从已登录即可使用运营功能改为 admin/user 分权 | 直接请求管理 API 也能验证普通用户被拒绝 | 三人联调 |
| 调用追踪 | 在结果和用量页核对能力、费用、状态和 requestId | 一条 requestId 贯穿 Gateway、调用、账单和结果 | 黄岑果 + 黄禹菲 |
